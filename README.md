# Excel Data Analytics Dashboards | Production & Business Performance

## Project Overview
Developed two interactive Excel dashboard projects to analyze business and production data and generate meaningful insights using Microsoft Excel.

### Dashboard 1: Production Analysis Dashboard
Analyzed production datasets to understand operational performance, production costs and manager contributions.

**Key Features:**
- Total production cost analysis.
- Product category-wise cost comparison.
- Manager-wise production performance.
- Units produced over time.
- Production cost per unit.
- Excel Pivot Tables and formulas.
- VLOOKUP, IF and calculated columns.

### Dashboard 2: Business Performance Dashboard
Developed a business analytics dashboard to evaluate financial performance and understand business trends.

**Key Features:**
- Revenue, Expenses and Profit analysis.
- Region-wise business performance.
- Department-wise financial analysis.
- Product-line revenue comparison.
- Customer segment analysis.
- Payment method-wise profit analysis.
- Pivot Tables and interactive data analysis.
